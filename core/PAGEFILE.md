# Подкачка Windows

Настройки → Подкачка Windows показывает обнаруженные системные файлы подкачки,
текущий объём и ограниченную оценку возможного роста. Кнопка включения запускает
отдельную PowerShell-команду через UAC с `AutomaticManagedPagefile=$true`.
Пользователь подтверждает системный запрос Windows. Astra не задаёт ручной размер,
не удаляет файлы подкачки и не перезагружает компьютер. В зависимости от текущей
конфигурации изменение может потребовать перезагрузки. Отмена UAC обрабатывается
как отмена, а не успешное применение.

Проверка памяти читает PagingFiles из реестра без повышения прав. Для системно
управляемых дисков учитывается возможное увеличение commit: до 3×RAM или 4 ГБ,
не более 1/8 объёма диска, с вычетом уже выделенной подкачки. Дополнительно Astra
ограничивает рост свободным местом с резервом 2 ГБ и максимумом 2×RAM. Это оценка
для допуска операции, не гарантия успешного выделения: Windows и другие приложения
могут изменить доступную память. Размер блоков и число потоков по-прежнему зависят
от физической ОЗУ. При неизвестной или фиксированной конфигурации прежняя строгая
проверка остаётся. Малый диск/нехватка места не превращаются в неограниченный допуск.

Настройки Windows на компьютере разработчика при тестировании не изменялись.
Проверены расчёты, отказ при отсутствии места, отсутствие роста при фиксированном
размере, команда включения и отмена административного запроса через имитацию.
