# Фон по эталону HiPS / HiPS reference background

Инструменты → Фон по эталону HiPS. Вычисления: `engine.py`, получение
обзора и геометрия: `reference.py`, интерфейс и ручная сверка: `ui.py`.

## Работа

На панели оставлены папка эталонов, её выбор и четыре основные кнопки.
Нажмите «Применить» либо «Предпросмотр»: Astra использует существующие WCS
или автоматически вызывает ASTAP с поиском по всему небу и подбором размера
поля. ASTAP и звёздный каталог должны быть установлены через настройки.
Ожидание решения ограничено пятью минутами, отмена останавливает процесс.

Затем программа использует сохранённый эталон или загружает DSS2 Red,
при неудаче пробует Pan-STARRS r и DSS2 Blue. Обзор и параметры коррекции
выбираются автоматически: плоская модель, защита слабых структур, сила 70%.
Эталоны сохраняются в выбранной папке. Сетевые ошибки не приводят к применению
результата без эталона.

Открывается окно сверки с результатом, наложением обзора, защитными областями
и просмотром удаляемого фона. После изменения областей нажмите «Пересчитать».
Проверьте результат, отметьте подтверждение и нажмите «Применить» в окне сверки
либо на основной панели. Только это действие записывает результат в историю.
Сам первый запуск подготовки исходные пиксели не изменяет.

Программа выделяет сомнительные участки сетки: возможные протяжённые структуры
или области с недостаточной опорой фоновых измерений. В окне сверки есть список
с причиной и статусом, жёлтая рамка и приближение выбранного участка.
Для каждого участка выберите «Вычитать здесь» или «Исключить из вычитания».
После выбора показывается следующий непроверенный участок. Решение можно
изменить, выбрав участок в списке. Применение невозможно до разбора всех
предложений и подтверждения общей проверки.

Исключённая область получает нулевую коррекцию, с плавным переходом снаружи.
Решения относятся к текущей модели; пересчёт сбрасывает их и запускает новую
сверку. Это эвристические подсказки по структуре собственного кадра и покрытию
фоновыми образцами, а не вероятность наличия туманности. Алгоритм не гарантирует
обнаружение всех спорных мест; пользовательские области защиты также доступны.

## Метод и ограничения

Обзор используется только для исключения объектов из фоновой выборки.
Его интенсивность никогда не вычитается из пользовательского кадра.
Дополнительное исключение звёзд и структур строится по самому изображению
на нескольких пространственных масштабах. Данные анализируются на выборке
до 1024 пикселей по стороне, с проверенной геометрией центров пикселей WCS.

Медианы сеточных участков аппроксимируются устойчивой регрессией. По умолчанию
используется плоскость; отключение «Сохранять слабые структуры» разрешает
квадратичную поверхность. Константа фона сохраняется. Сила 0…100%; расчёт RGB
поканальный, вывод float64 без нормализации и обрезки диапазона. Применение
блоками, при необходимости выходной массив находится на диске.

Ручные защищённые прямоугольники исключены и из оценки, и из коррекции;
снаружи защита плавно ослабляется. Автоматическая защита исключает точки
из оценки, но не гарантирует сохранения неизвестной протяжённой туманности:
такую область следует защитить вручную. Слишком широкая защита может оставить
часть градиента, а отсутствие распределённых участков фона останавливает расчёт.
Активная маска дополнительно ограничивает коррекцию и учитывается в предпросмотре.

Это коррекция плавного аддитивного фона. Она не восстанавливает корректно
чувствительность в пылевых пятнах и виньетировании: для них нужны флеты.
Резкие локальные пятна и разделение дефектов по нескольким съёмочным сериям
не реализованы. Цветовой обзор не является спектральным эталоном Hα/OIII.
WCS с SIP поддерживается: обзор запрашивается на линейной сетке и локально перепроецируется с учётом искажений.

Сетевые запросы выполняются в фоне, имеют ограничение размера и тайм-аут,
используют официальный HTTPS-сервер и зеркало. Отмена проверяется между
блоками; ожидающее сетевое чтение может завершиться только по тайм-ауту.
Перед применением обязательна ручная проверка; изменение параметров, областей,
источника или активной маски требует нового предпросмотра. Параметры инструмента и ручные области сохраняются в проекте. Эталоны при включённой настройке сохраняются в выбранной папке и повторно используются без сети. По умолчанию это `%LOCALAPPDATA%/Astra/hips-cache`. FITS снабжается контрольной суммой; повреждённая копия не используется. Текущий эталон можно отдельно сохранить через диалог FITS. Подтверждение ручной сверки после открытия проекта выполняется заново.

Документация сервиса: https://alasky.cds.unistra.fr/hips-image-services/hips2fits
Официальный клиент: https://docs.astropy.org/en/stable/ (WCS),
https://astroquery.readthedocs.io/en/latest/hips2fits/hips2fits.html

## Проверки

`test_reference_background.py`: удаление синтетического градиента; сохранение
защищённой туманности, отсутствующей в обзоре; неизменность исходника;
RGB/моно; нулевая сила и маска; NaN; отмена; недостаток фоновых участков;
независимость результата от абсолютной яркости обзора; точность WCS;
проверка ответа сервиса и локального FITS; обязательная ручная проверка,
сброс подтверждения после смены параметров, применение и отмена через историю.

Живая загрузка 2026-11-04 не подтверждена: оба сервера CDS завершили соединение
по тайм-ауту. Приём корректного FITS и отказ при неверной геометрии проверены
на контролируемых ответах сервиса, чтение локального FITS проверено отдельно.
