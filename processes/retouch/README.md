# Ретушь

`engine.py` выполняет обработку float64 в исходных единицах, `ui.py` собирает
мазки на активном изображении. Восстанавливающая кисть после каждого мазка
показывает рабочую копию прямо в исходном окне; отдельного предпросмотра нет.
До подтверждения данные документа и история сохраняются. «Применить» принимает
готовую рабочую копию без повторного расчёта, создавая один checkpoint.
«Сброс» и «Отмена» возвращают исходное отображение. Предрастяжка вычисляется
по исходному состоянию, чтобы не компенсировать локальные изменения ретуши.
У ручного штампа остаётся отдельное окно предпросмотра. Файлы не перезаписываются.

Штамп: Alt + клик выбирает источник. Первый мазок задаёт постоянное смещение
источника, следующее Alt + нажатие сбрасывает его. Донор всегда читается из
исходного состояния перед ретушью: штамп не размножает уже нанесённую ретушь.

Автоштамп: детерминированный поиск 64 соседних доноров на расстояниях 3, 5, 8,
12 радиусов. Сравнивается текстура кольца 0.72–1 радиуса, с робастной оценкой
ошибки и компенсацией медианы по каналам. Доноры вне кадра, содержащие NaN/Inf
или перекрывающие планируемые мазки, исключаются. Выбранный участок согласуется
с фоном через смещение медианы. Это локальная эвристика, не алгоритм Photoshop.
Окружность кисти должна охватывать артефакт; возле сложных структур и краёв
может потребоваться ручной штамп. Ретушь синтезирует замену, не восстанавливает
утраченный астрономический сигнал.

Параметры каждого мазка фиксируются при рисовании. Мягкость задаёт ширину
плавного края, сила — смешивание с текущим результатом. Маска 0…1 ограничивает
эффект. Неконечные пиксели исходного кадра сохраняются; область штампа за краем
источника не применяется. Прогресс и отмена работают между мазками и при поиске.
Лимиты: радиус до 150 пикселей, до 3000 точек на сеанс; большие области лучше
исправлять несколькими небольшими сеансами.
