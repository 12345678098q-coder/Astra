# Диагностика бета-версии

Перед упаковкой стабильной версии в `core/build_flags.py` установите
`BETA_DIAGNOSTICS = False`. Это отключает постоянный журнал Astra, faulthandler,
перехват ошибок интерфейса и подключение диагностического окна. Обычный журнал
выполнения инструментов в интерфейсе остаётся: он нужен для прогресса и ошибок.

При этом значении из дистрибутива можно исключить `core/diagnostics.py`,
`diagnose_compatibility.py`, `diagnose_cpu.bat`, `start_cpu.bat`, каталог `fixes`
и тесты. `core/build_flags.py` необходимо оставить. Обычный запуск через app.py
не импортирует diagnostics при выключенном флаге. Не переносите журналы из
профиля разработчика в архив. Существующие журналы пользователя не удаляются.

Режим совместимости CPU и диагностическое логирование независимы:
`compatibility.flag` управляет ресурсами, `BETA_DIAGNOSTICS` управляет диагностикой.
