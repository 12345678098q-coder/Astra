# Базовые архивы и установщики

Машиночитаемый флаг: `package-policy.json`, `base_bundle_include_cuda: false`.
Он относится ко всем будущим базовым архивам и установщикам.
Применяйте исключения к staging-каталогу, не к рабочей `.venv` разработчика.

Не копируйте `.venv` целиком. Runtime собирайте из `requirements.txt`.
Не добавляйте `requirements-cuda.txt` к команде установки базовых зависимостей.
Сам этот файл обязательно положите рядом с `app.py` в дистрибутив.
Оставьте `runtime/python.exe` и pip: они нужны пользователю для установки GPU.
Встраиваемый Python без pip не удовлетворяет этому контракту.

CUDA-компоненты (`cupy*`, `cuda*`, `nvidia*`) и папка `optional/cuda` из базовой сборки исключаются.
Inno Setup применяет дополнительный фильтр в Astra.iss.
Для ZIP используйте ту же политику и перед упаковкой обязательно выполните:

    python build-support/check_package.py release/Astra-1.0.0

Ненулевой код означает, что базовую сборку публиковать нельзя. Проверка ничего
не удаляет. Не включайте кэши, тесты, скриншоты, PyInstaller и другие артефакты
разработки. Не распространяйте активированную RC-Astro и лицензионные данные.
GraXpert/StarNet/ASTAP и их модели управляются отдельно средствами Astra.

В приложении: «Настройки → Поддержка NVIDIA GPU». Диалог показывает наличие
CuPy, папку Python текущей Astra и команду PowerShell для установки
`requirements-cuda.txt`. Все GPU-зависимости перечислены явно и устанавливаются
с флагами `--no-deps --target "<папка Astra>/optional/cuda/site-packages"`.
Это предотвращает дублирование NumPy и обновление базовых зависимостей.
Пользователь закрывает Astra, запускает команду и снова открывает приложение.
Команда использует `.venv/Scripts/python.exe` для исходников или
`<папка Astra>/runtime/python.exe` для установленной версии.
GPU-пакеты лежат отдельно от этого Python и подключаются Astra при выборе GPU.
Не нужно копировать DLL в Windows/System32 или устанавливать пакеты
в посторонний системный Python. Без CUDA базовая обработка работает на CPU.

GPU-пакеты рабочего проекта перенесены из `.venv` в `optional/cuda/site-packages`.
Установленные ранее архивы/установщики автоматически не перепаковываются.
Не копируйте папку optional в базовый staging-каталог. Установщик должен
использовать доступную пользователю для записи папку (текущий Inno Setup
использует LocalAppData/Programs/Astra без прав администратора).
