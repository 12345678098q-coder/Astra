# Коррекция краёв

По умолчанию используется встроенный экспериментальный алгоритм Astra.
Галочка «Использовать BlurXTerminator» доступна при обнаружении RC-Astro CLI
через настройки, PATH или стандартный путь установки. Наличие исполняемого
файла не подтверждает лицензию BXT: её проверяет RC-Astro при запуске.

Встроенный режим оценивает ковариацию изолированных звёзд в исходном
разрешении. Нужно не менее восьми подходящих звёзд. Опорная ширина берётся
по 25-му процентилю меньших собственных значений ковариаций. Локальная
избыточная ковариация ограничена положительными значениями до 9 пикселей².
В перекрывающихся областях 192×192 с шагом 96 выполняется регуляризованная
обратная фильтрация гауссовой PSF с отражённым полем 32 пикселя. DC сохраняется,
усиление ограничено 2.5. Области смешиваются плавными весами sin². Цветовые
каналы используют общую PSF. Astra плавно подмешивает результат к краям,
защищая центральные 35% радиуса и учитывая активную маску.

Это приближённая модель: асимметричные хвосты комы, кольца сильного
расфокуса и утраченные детали она надёжно не восстанавливает. По наиболее
резким звёздам нельзя восстановить неизвестную исходную PSF. После
асимметричного кадрирования центр поля может не совпадать с оптическим центром.
Рекомендуются линейные кадры до удаления звёзд. Значения не обрезаются,
отрицательные значения допускаются; неопределённые пиксели и их окружение
сохраняются. Применение создаёт EDGE в истории, предпросмотр её не меняет.

Общий принцип регуляризованной деконволюции описан в
[документации scikit-image](https://scikit-image.org/docs/stable/api/skimage.restoration.html#skimage.restoration.wiener).
Здесь используется собственный фильтр Astra с ограничением усиления;
это не точная реализация Wiener-Hunt из scikit-image и не аналог BXT по качеству.

Проверки: синтетическое поле с ростом гауссова размытия к краям, сохранение
центра, соотношений RGB и исходного массива, нулевая сила, маска, NaN/Inf,
отмена и сообщение при недостатке звёзд. Проверены независимый запуск без
RC-Astro, предпросмотр, применение и откат истории, а также передача в BXT
через тестовую замену внешнего процесса. На реальном пользовательском кадре
качество нового алгоритма пока не оценивалось.

# Предпросмотр кривых

R/G/B отрисовываются красным/зелёным/синим; общая кривая белая,
яркость жёлтая, насыщенность пурпурная. Изменение узлов автоматически
обновляет открытый временный предпросмотр. Его параметры предрастяжки
вычисляются по исходному кадру и фиксируются при показе результата,
поэтому повторный автоподбор не компенсирует правку кривой. Исходное
изображение и его история обновляются только при применении. Прямая
кривая сохраняет данные без изменений. Новые файлы кода загружаются
после перезапуска Astra, открытый ранее процесс их автоматически не подхватывает.
