# Проверка Astra, 9 ноября 2026

Первый изолированный прогон охватил 92 тестовых файла: 81 прошёл, 10 завершились ошибкой, один превысил 90 секунд. В завершившихся unittest-прогонах было 296 тестов; скриптовые проверки учитываются отдельно. После повторного запуска зависавший test_native_tools завершился с ошибкой утверждения. Итог по файлам: 81 прошёл, 11 требуют разбора. Общий набор не является полностью успешным.

Новые целевые проверки после последних правок: **12 тестов, все прошли**. Проверены моно/RGB 1536×1024, тождественные операции и отсутствие изменения входов, монотонность/обратимость растяжения, аналитическая калибровка, подавление синусоидальной помехи с сохранением DC, звёздные профили, расширение мозаики, временные сдвиги кометы, реконструкция CFA, спектрофотометрическая калибровка, все новые диалоги и рабочий live-сеанс из двух FITS.

## Найденные проблемы общего набора

- test_compatibility_package: внутри песочницы блокируется CIM; повтор вне песочницы подтвердил отдельную проблему – несовпадение контрольной суммы processes/native/advanced_ui.py в существующем пакете и манифесте. Пакет не пересобирался.
- test_edges: установленный внешний ASTAP не запускается в среде проверки, WinError 623.
- test_interface_settings: ожидаемое увеличение высоты кнопки при смене плотности не происходит.
- test_linked_quality_recovery: ожидание пунктов контекстного меню не соответствует фактическому меню.
- test_localization: ожидание подписи панели не соответствует текущему содержимому.
- test_narrowband: несовпадение ожидаемого display_range предпросмотра.
- test_native_tools: после устранения блокирующего модального окна выявлено несовпадение ожидаемого состояния предпросмотра.
- test_palette_auto_masks: отсутствует модель real_colour_controls_v5_experimental.npz.
- test_palettes, test_projects: ожидание исходного названия не совпадает с фактическим уникальным названием с суффиксом копии.
- test_signal_booster_structure: импорт multiscale не разрешается в существующем сценарии.

Эти ошибки обнаружены в текущем рабочем дереве с уже имевшимися изменениями. Отдельная чистая базовая версия не запускалась, поэтому их происхождение по этому прогону не установлено.

Полные журналы первого изолированного прогона: tests/testing-isolated-results.json. Повторные диагностические проверки: tests/testing-recheck-results.json. Исходный общий discovery-прогон был прерван из-за GUI при импорте старого скриптового теста.

В headless Qt системный список шрифтов оказался пуст; для повторов тестовый harness загружает Segoe UI явно. После загрузки шрифта сделан и визуально проверен tests/testing-spcc.png: подписи читаемы, поля и кнопки помещаются. Первый снимок с отсутствующими шрифтами заменён. Рабочие снимки пользовательских изображений для оценки качества не предоставлялись.
