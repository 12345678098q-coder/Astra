# Подборка «На тест»

Инструменты открываются через Инструменты → На тест. Live stacking расположен отдельным верхним меню. CFA Drizzle перенесён в модуль сложения → Настройки сложения → Drizzle и отсутствует в «На тест». Все вычисления выполняются внутри Astra с установленными зависимостями; новая внешняя программа не требуется. Результаты экспериментальных инструментов открываются отдельными изображениями.

## Доступные расчёты

- Спектрофотометрическая калибровка: интегрирование спектров каталожных звёзд по откликам системы, апертурная фотометрия по WCS, робастная медиана коэффициентов RGB. Требуются линейные данные и минимум пять пригодных звёзд.
- Гиперболическое растяжение: нормированный интеграл гиперболического ядра контраста с линейными участками защиты теней и светов, обратное преобразование. Это собственная параметризация Astra.
- Мозаика: поиск общих звёзд, цепочки перекрытий, расширенное поле, плавные переходы, аддитивное согласование фона в перекрытиях. Поддержаны NaN на непокрытых краях. Геометрия – преобразование подобия, без проективной/оптической коррекции.
- Комета/астероид: автоматическое совмещение по звёздам, вычитание медианного фона серии и поиск согласованной траектории движущегося источника. Нужны минимум три откалиброванных кадра и заметное движение. DATE-OBS задаёт порядок и интервалы. При отсутствии времени во всей серии используются порядок списка и равные интервалы. Результат сначала показывается внутри модуля. Поддерживается приближённо прямолинейное равномерное движение.
- Подавление полос: вычитание медианных поправок строк или столбцов. При протяжённых структурах вдоль полос проверяйте результат.
- Звёзды: подгонка кругового Gaussian по незасвеченным крыльям, реконструкция засвеченного ядра. Это модельное восстановление, а не возврат потерянных измерений.
- CFA Drizzle в модуле сложения: включите Drizzle и CFA Drizzle, выберите Bayer RGGB/BGGR/GRBG/GBRG либо RAW в основном окне. Калибровка Dark/Flat и косметика выполняются по исходной CFA-матрице. Дебайер используется только для регистрации. Доступны масштабы 1–3, pixfrac, среднее/медиана и MAD/сигма/винзоризованная отбраковка при наличии пяти отсчётов на пиксель канала. Промежуточные RGB и карты весов хранятся в дисковом кеше, интеграция идёт блоками. COVERAGE содержит сумму принятых пространственных весов. Пользовательские веса кадров, как и в обычном Drizzle, не применяются. При малом покрытии возможны NaN. Начните с масштаба 1× и pixfrac 1. Коррекция смаза несовместима с CFA Drizzle и отключается в настройках.
- Расширенная калибровка: Bias/синтетический Bias, Dark, Flat, Dark Flat, масштаб Dark по выдержке либо оценке на высокочастотном фоне, выравнивание CFA Flat. Обработка активного изображения; это не замена основного конвейера сложения. X-Trans в эту реализацию не входит.
- Live stacking: поступающие FITS, проверка стабильного размера файла между опросами, Bayer-дебайер, регистрация и среднее с покрытием, пауза/продолжение, новая сессия. Используются предварительно откалиброванные кадры. Ошибка кадра останавливает наблюдение и отображается пользователю; после исправления можно продолжить. RAW и калибровка мастерами внутри live-режима пока не поддерживаются.

## Спектральные файлы

UTF-8 CSV с разделителем-запятой. Поля с JSON-массивами должны быть экранированы по правилам CSV.

- Каталог: `ra`, `dec` (градусы), `flux` (JSON-массив Fλ), необязательный `wavelength` (JSON-массив длин волн в нм). При отсутствии wavelength используется равномерная сетка 336–1020 нм.
- Отклики: `wavelength,R,G,B`, возрастающая сетка в нм; неотрицательные полные отклики камеры и фильтров. Каталожные спектры должны покрывать сетку откликов.
- Белый эталон: `wavelength,flux`. Без файла используется равная энергия Fλ. Автоматической загрузки каталогов и базы оборудования пока нет.

## Извлечение каналов

В быстрых кнопках яркость L находится рядом с RGB и использует сходный значок из трёх плоскостей. Правая кнопка на RGB открывает выбор RGB/R/G/B. Яркость вычисляется как линейная Rec.709: 0.2126 R + 0.7152 G + 0.0722 B. Исходное изображение сохраняется; WCS переносится, если присутствует. Для гамма-кодированных обычных фотографий предварительное снятие гаммы автоматически не выполняется.

## Проверка

Новые целевые проверки находятся в tests/test_testing_tools.py. Широкий изолированный прогон: scripts/run_isolated_tests.py. Он использует отдельные процессы, временные настройки и автоматическое закрытие немокированных модальных окон; интерактивные диалоги сохранения этими проверками вручную не подтверждались. Тесты с собственными mock сохраняют собственную логику.

Численное совпадение с другими программами не проверялось. Проверки выполнялись на синтетических изображениях, включая 1536×1024 моно/RGB, известные спектры и WCS, геометрические сдвиги и имитацию поступления FITS. Требуется дальнейшая оценка на реальных сериях пользователя.
