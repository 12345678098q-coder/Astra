# Signal Booster pilot

Экспериментальный нейросетевой инструмент для калиброванных линейных моно/RGB
стеков. Открывается в текущей Astra через меню «Инструменты → Signal Booster · pilot».
Укажите, что данные линейные, начните с силы 50% и предпросмотра. Применение
поддерживает пользовательскую маску, историю и отмену. Перезапустите Astra,
если приложение было открыто до добавления инструмента.

Модель `models/signal_booster_pilot.npz` содержит числовые веса трёхслойной
остаточной CNN. Все RGB-каналы обрабатываются одной сетью независимо.
Расчёт идёт на CPU плитками с перекрытием контекста. Результат не обрезается
в диапазон 0…1. Величина изменения ограничена оценкой шума, сила 0 точно
возвращает исходные данные. Тип линейности подтверждает пользователь.

## Тестовое обучение

601 шаг Adam, патчи 64×64, по 12 патчей на шаг. Обучающие объекты — Тюльпан,
Розетка и Полумесяц. Шлем Тора используется для выбора контрольной точки,
западная Вуаль открывается для итоговой проверки после выбора модели.
Вход каждого канала — среднее двух настоящих экспозиций, эталон — среднее
шести других экспозиций того же проекта. Имена и SHA-256 записаны в `data/*.json`.
Источники калиброваны master dark и master flat, совмещены по звёздам и
уменьшены до 900 px. Растяжка и искусственное добавление шума при обучении
не используются. Общие калибровочные мастера и интерполяция могут создавать
коррелированные ошибки. Тестирование на одной камере и двух отложенных
объектах ограничивает выводы о других инструментах и объектах.

При силе 50% MSE относительно независимого шумного эталона уменьшилась
примерно на 0.65% у Шлема Тора и на 0.85% у западной Вуали. В более слабых
областях улучшение больше. Достоверность отдельных слабых деталей и
эквивалентное увеличение времени экспозиции ещё не измерены.

Проверен простой контрольный метод — гауссово сглаживание. Sigma 0.3 выбрана
на Шлеме Тора и затем применена к Вуали. Его полнокадровая MSE ниже, чем
у нейросетевого пилота на обоих объектах. Практическое преимущество сети
над обычным фильтром этим экспериментом пока не установлено.

Полные числа находятся в `report.json`. В `comparison.jpg` вход, результат
сети и независимый эталон показаны с одной растяжкой, рассчитанной по входу.

## Повторный запуск

Из корня проекта, используя текущую `.venv`:

```powershell
.venv/Scripts/python.exe -m pip install torch --index-url https://download.pytorch.org/whl/cpu
.venv/Scripts/python.exe experiments/signal_booster/experiment.py train
.venv/Scripts/python.exe experiments/signal_booster/experiment.py apply --input linear.tiff --output result.tiff
.venv/Scripts/python.exe -m unittest test_signal_booster
```

В текущем окружении установлен PyTorch 2.15.0+cpu. Установка в готовую
portable-сборку ещё не подготовлена. FITS входы читаются через astropy,
результат командной строки сохраняется в TIFF. Обучающий скрипт требует
локальные исходники `PaletteLab/training/real_pairs_v2/sources/moana`.

Обработка в этом эксперименте включает калибровку, регистрацию, изменение
размера, сложение и обучение модели.
