# Astra Palette Lab · экспериментальная версия 0.2

Запуск: `Start-PaletteLab.bat`. Используется Python из соседней `.venv`.
Основная Astra и CUDA не меняются. Для отдельной установки: Python 3.12,
`pip install -r requirements.txt`.

## Модель на реальных данных

Файл: `models/real_colour_controls_v6_masks_experimental.npz`. В списке программы доступна только `V6`; прежние модели хранятся в архиве обучения.
Устойчивое улучшение любых снимков пока не подтверждено: на некоторых объектах
коррекция ухудшает цвет. Это экспериментальная модель, не готовый универсальный автокорректор.

Модель предсказывает 27 параметров: монотонные кривые RGB и общую кривую,
баланс, насыщенность теней/средних тонов/светов, дополнительный акцент HOO.
Результат получается преобразованием исходного RGB каждого пикселя.
Генерации изображения, перемещения звёзд и дорисовки деталей нет.
Шумоподавление, деконволюция и удаление пространственных градиентов не выполняются.

Текущая V6 усредняет настройки трёх ближайших обучающих примеров
по 40 статистикам кадра и применяет половину предсказанной поправки параметров.
Этот вариант выбран по объектной перекрёстной проверке и валидации;
сравнивались также RBF/линейная регрессия и усреднение. Это подбор параметров по ближайшему примеру,
а не большая нейросеть. Подбор и применение выполняются на CPU.
Список CUDA вверху окна относится к совместимости со старыми MLP-моделями.

## Применение

1. На вкладке «Применение» нажмите «Загрузить модель»: диалог открывается на файле v6.
2. Готовое растянутое RGB-фото открывайте через «Открыть фото». Для линейного
   FITS/TIFF используйте «Открыть линейный стек»: выполнятся нейтрализация фона
   и общая растяжка RGB, рассчитанные только по самому стеку. Это отдельная
   подготовка, не результат обучения. Готовые фотографии повторно растягивать не нужно.
3. Для текущей палитры оставьте «Режим модели». HOO-акцент усиливает уже имеющийся
   красный/бирюзовый сигнал. Его регуляторы ручные; отдельная обобщающая HOO-модель
   пока не обучена. Hα/OIII из обычного RGB не измеряется и не восстанавливается.
4. Нажмите «Рассчитать», сравните результат. Сила 0 точно сохраняет вход.
   «Сохранять яркость» сохраняет сумму RGB Rec.709, не фотометрическую калибровку.
   Для v4 флажок при загрузке отключается: модель обучалась также менять тон.
   Метрики ниже рассчитаны при силе 100% без сохранения яркости.
5. «Показать настройки» показывает кривые, баланс и насыщенность. JSON сохраняет
   также силу и сохранение яркости, необходимые для повторения обработки.
6. Сохраните отдельный FITS или float32 TIFF. Растяжка только просмотра экспорт
   не меняет. FITS-заголовок, WCS и исходные метаданные не переносятся.

Renderer v2 сохраняет чёрную и белую точки и сжимает насыщенность у границы
диапазона; результат остаётся в 0…1. Старые MLP и renderer v1 могут выдавать
значения вне диапазона: при экспорте они сохраняются, при просмотре обрезаются.
Исходники не меняются, если явно не выбрать их путь при сохранении.

Текущий инструмент Palette AI в Astra использует NebulaMaskBuilder 1.2 AUTO
внутри расчёта. Маски не публикуются как изображения и не требуют образцов
или ручного запуска модуля. Используются фон и две цветовые компоненты HOO;
это классификация RGB, не измерение спектральных линий. Дополнительная мягкая
защита компактных ярких структур уменьшает воздействие на звёзды.

Настройки предсказываются по целому исходному кадру.
На реальных обучающих парах отдельно обучены три ограниченных коэффициента
применения по областям, выбранные на трёх других валидационных объектах:
фон 0.25, тёплая и холодная компоненты 1.0. Они действуют поверх уже умеренной
коррекции параметров. Отдельные кривые для каждой области не обучались.
Мягкое смешивание преобразует исходные пиксели; генерации изображения нет.
При недостаточном цветовом сигнале результат равен исходнику, причина видна
в журнале. Включённая пользовательская маска дополнительно ограничивает эффект.

На четырёх повторно использованных проверочных объектах CIEDE2000:
M31 4.828 → 4.784; NGC281 5.101 → 5.129; NGC7000 8.093 → 7.932;
M27 8.138 → 8.147. Изменения малы; два объекта всё ещё слегка ухудшаются.
Это исследовательская оценка, не новый слепой тест. Полный протокол:
`training/real_pairs_v2/mask_adapter_results.json`.
В старых моделях, выбранных внутри инструмента Astra, применяются базовые
автоматические маски; обученная политика хранится именно в v6.
Если в настройках сохранён выбор v5, выберите v6 в существующем списке модели.

## Собственное обучение

Добавляйте реальные пары одного поля неба, предпочтительно FITS/TIFF.
Растяжка должна быть сопоставимой, различаться должен преимущественно цвет.
Линейные стеки сначала отдельно подготовьте и сохраните: при обучении
начальная растяжка автоматически не применяется.

Укажите одинаковую «Группу объекта» всем его версиям, даже с разных камер.
Нужны минимум 4 независимые группы: 3 обучающие и 1 проверочная.
Последняя группа целиком откладывается для проверки. Минимальный набор
не доказывает хорошего обобщения. Подтвердите пары, выберите режим,
число шагов подбора, обучите и сохраните NPZ. Шаги — лимит оптимизации
рецептов, не эпохи большой сети. Встроенный простой подбор пользовательской
модели отличается от расширенного исследовательского перебора v4.

Автосовмещение учитывает сдвиг, поворот и равномерный масштаб. Зеркала
и дисторсию подготовьте самостоятельно. Для совмещённых пар его можно отключить.
Unsigned нормируется полным диапазоном типа; для растянутых float выберите
0…1 либо 0…65535. Моно, NaN/Inf и неверный диапазон отклоняются.
Длительные операции идут в рабочем потоке с отменой между блоками.
Чтение большого файла и отдельный поиск звёзд могут не прерываться немедленно.
Полные исходники и результат находятся в ОЗУ.

`python -m unittest test_engine test_alignment test_colour_controls test_editor_model test_display_stretch`

преобразование, границы цвета, регрессия, разделение объектов и растяжка.
Синтетические fixtures используются только для технических тестов.
